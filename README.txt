PRIMERA EJECUCIÓN

1. Clonar el repositorio.

2. Crear la configuración:

   copy config\database.env.example config\database.env

3. Completar las credenciales PostgreSQL en:

   config\database.env

4. Preparar FoodFlow:

   scripts\setup.bat

5. Abrir:

   FoodFlow.exe


EJECUCIONES POSTERIORES

Doble clic en:

   FoodFlow.exe
